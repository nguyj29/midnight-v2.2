You are organising a music folder. There are 35 instrumental audio files, each named by a random id (for example t68bc6fa5.mp3). They are in two folders, labeled/ and unlabeled/ (possibly with other audio extensions). Sort them into three tier folders, S, A and B, in ranked order, using the list below.

RULES
1. Create three folders next to labeled/ and unlabeled/: S, A and B.
2. For each line "N - <id>" under a tier, find the file whose name (without extension) is exactly <id>, in labeled/ or unlabeled/.
3. COPY it (don't move or delete anything) into that tier's folder, renamed to "N - <id>.<ext>". If the line ends with "(predicted)", keep that in the name: "N - <id> (predicted).<ext>".
4. N is the place inside the tier (1 = top). Keep the numbers exactly as listed; don't renumber, re-rank or skip.
5. Never overwrite an existing file. If an id can't be found, don't guess: list it at the end as missing.
6. When done, report the number of files in S, A and B (expected 11, 15 and 9), plus any missing ids.

    python sort_into_tiers.py          (dry run)
    python sort_into_tiers.py --go     (copies into tiers_sorted/S, A, B)
