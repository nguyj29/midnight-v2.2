# Tie-breaks: side-by-side comparisons inside a shared slot

Each unlabelled track was slotted by comparing it side by side with the labelled tracks (six anchors, then the
labelled tracks on both sides of its slot; see `<id>.md`). Where several unlabelled tracks landed in the same slot,
they were then compared **with each other**, every pair, using their listening notes and the taste profile
(mood first, then impact, then breathing). A track's order in the slot = number of pairwise wins.
